# 🌍 Equflope — DisasterGuard-AI

A web-based disaster map interface designed to display disaster-related information for floods and earthquakes.

## 🚀 Features

- 🗺️ Interactive map using Leaflet and OpenStreetMap
- 🔎 Location search and autocomplete interface
- 🆘 SOS button interface
- 📊 Historical data and prediction display controls
- 🌐 Location-based disaster information display

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Leaflet
- OpenStreetMap
- External libraries: Tailwind CSS and SweetAlert2

## 📦 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Nitinn12/DisasterGuard-AI.git
```

### 2. Open the project folder

```bash
cd DisasterGuard-AI
```

### 3. Run the application

Open the `index.html` file in your web browser.

Alternatively, open the project folder in Visual Studio Code and use the **Live Server** extension to run the page locally.

**Note:** An internet connection is required to load external libraries and OpenStreetMap tiles.

## ⚠️ Important Notes

- The recovered HTML contains mock/sample disaster data.
- Displayed predictions are not verified real-time flood or earthquake forecasts.
- This repository currently contains the recovered HTML interface, not necessarily the complete original Android app source code, backend, dataset, or trained ML model.
- The SOS button is an interface element and should not be assumed to contact emergency services.
